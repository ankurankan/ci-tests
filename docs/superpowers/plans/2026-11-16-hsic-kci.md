# HSIC and KCI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port pgmpy's HSIC and KCI conditional-independence tests into `ci_core` and expose them in the Python, R and JS bindings with golden-fixture and pgmpy-parity coverage.

**Architecture:** Two new `CITest` implementations (`Hsic`, `Kci`) in `ci_core`, built on a small public `kernel` module (kernel/bandwidth/kernel-choice types plus dense kernel helpers on `faer` matrices) and an in-crate SplitMix64 RNG for permutation nulls. Each binding gets thin wrappers that parse kernel options and call a new provided `CITest::validate` hook at construction. The language-neutral golden fixture gains an independent numpy reference and a per-case relative tolerance.

**Tech Stack:** Rust 2021 (`faer` 0.24, `statrs` 0.18), PyO3/maturin, extendr/R (conda-installed locally), wasm-bindgen/wasm-pack + vitest, Python fixture tooling (numpy, scipy).

**Spec:** `docs/superpowers/specs/2026-11-14-hsic-kci-design.md` — read it first; its "Math" section is the normative definition of every formula referenced below. pgmpy reference: commit `cf069b04a12d7858dcb659221128371909f78112`, `pgmpy/ci_tests/hsic.py` and `kci.py` (snapshot: `/tmp/claude-1000/-home-ankur-work-pgmpy-ci-tests/1caf9050-6f9c-4107-a19b-c282dc5333a9/scratchpad/pgmpy-dev`; also `upstream/dev` in `../pgmpy`).

- Formatting/lints as today: `cargo fmt`, clippy pedantic `-D warnings`, ruff, eslint/prettier, lintr/styler.

## Review Focus

1. **n too large for a dense n×n matrix** (e.g. wasm32 at n ≳ 23 000, or `n*n*8` overflowing `isize`): expect `CiError::DegenerateData`, never a capacity-overflow panic — test in Task 3 (`dense_len_guard_rejects_overflow`).
2. **Dataset with unrelated discrete columns**: HSIC/KCI on continuous X/Y/Z must work when other columns are discrete — tests in Tasks 4 and 5.
3. **Perfectly dependent variables** (Y identical to X, or Y = 2X): finite statistic and tiny p-value, no error (unlike `PearsonCorrelation`'s ±1 error) — tests in Tasks 4 and 5.
4. **Per-column kernel map naming a column absent from the dataset**: error at construction in every binding (pgmpy raises `ValueError`) — tests in Tasks 3, 4, 8, 9, 10.
5. **Out-of-range binding inputs** (negative/huge/non-integer `seed`, `n_permutations = 0`, `epsilon ≤ 0` or NaN, `length_scale ≤ 0`, unknown `bandwidth`/`null_dist`/kernel `type`): clean error, never a panic or silent coercion — tests in Tasks 8, 9, 10.

**Files:**

**Interfaces:**

  - `impl Kernel { pub fn validate(&self) -> Result<(), CiError> }` — RBF `length_scale` finite and > 0, else `CiError::InvalidConfig`
  - `impl KernelChoice { pub fn validate(&self, data: &Dataset) -> Result<(), CiError> }` — validates every kernel; every `PerColumn` key must name a column of `data` (`CiError::UnknownColumn`)
- Produces (public, `ci_core::error`): new variant `CiError::InvalidConfig(String)` with `#[error("invalid configuration: {0}")]`.
- Produces (crate-private, in `kernel.rs`), row-major points as `faer::Mat<f64>` (n rows × d columns):
  - `pub(crate) fn dense_len_guard(n: usize) -> Result<(), CiError>` — `DegenerateData` if `n*n*8` overflows `isize`
  - `pub(crate) fn standardized(data: &Dataset, cols: &[usize], scale: f64) -> Result<faer::Mat<f64>, CiError>` — stacks the columns, each standardized with ddof = 1 then multiplied by `scale`; `DegenerateData` if n < 2 or a column has zero variance; `WrongColumnKind` for discrete columns (via `Dataset::continuous`)
  - `pub(crate) fn kernel_matrix(kernel: Kernel, points: faer::MatRef<'_, f64>) -> faer::Mat<f64>` — RBF via `exp(-0.5 * sqdist(a/ℓ, b/ℓ))` (sklearn order), Linear via `a·b`
  - `pub(crate) fn center(k: &mut faer::Mat<f64>)` — spec centering formula
  - `pub(crate) fn median_length_scale(points: faer::MatRef<'_, f64>) -> f64` — spec median rule; `1.0` when no non-zero distance
  - `pub(crate) fn gamma_pvalue(stat: f64, mean: f64, var: f64) -> Result<f64, CiError>` — spec rule via `statrs::distribution::Gamma` (rate = 1/scale) `sf`
